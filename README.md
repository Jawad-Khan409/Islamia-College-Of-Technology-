# Islamia College — GitHub Pages Front-End

Pure front-end project using only HTML, CSS and JavaScript.

## Pages
- `index.html` — landing page
- `login.html` — demo login
- `signup.html` — demo registration
- `dashboard.html` — demo student dashboard

## GitHub Pages
Upload all files to the root of a GitHub repository, then enable:
**Settings → Pages → Deploy from branch → main → / (root)**.

No backend, database, Flask, Node.js or build step is required.

The demo authentication stores one demo user in browser `localStorage`; it is not real production authentication.
